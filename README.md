# StudentIQ — Predicting Final Exam Marks Using Machine Learning Regression

**Domain:** Student Academic Performance
**Type:** Regression (Linear Regression & Polynomial Regression)
**Deployment:** Streamlit web app

## 📌 Problem Statement

Predict a student's final academic score using attendance, study hours, internal marks, assignment performance, and other related factors.

## 📂 Project Files

| File | Description |
|---|---|
| `Student_Final_Marks_Prediction.ipynb` | Full Jupyter notebook: EDA, preprocessing, model training (Linear + Polynomial Regression), evaluation (MAE, MSE, RMSE, R²), and interpretation. Already executed, with all outputs and charts saved. |
| `app.py` | Streamlit web app that loads the trained model and predicts final marks from user input. |
| `Final_Marks_Data.csv` | Source dataset (2,000 student records). |
| `final_marks_model.pkl` | Trained Linear Regression model (generated by the notebook). |
| `feature_scaler.pkl` | Fitted `StandardScaler` used to scale inputs (generated by the notebook). |
| `feature_columns.pkl` | Ordered list of feature column names expected by the model. |
| `requirements.txt` | Python dependencies. |
| `StudentIQ_Project_Documentation.docx` | Full project documentation with detailed code explanations (space left for screenshots). |

## 🧠 Dataset

`Final_Marks_Data.csv` — 2,000 rows, 7 columns:

- `Student_ID` — unique identifier (dropped before modelling)
- `Attendance (%)`
- `Internal Test 1 (out of 40)`
- `Internal Test 2 (out of 40)`
- `Assignment Score (out of 10)`
- `Daily Study Hours`
- `Final Exam Marks (out of 100)` — **target variable**

No missing values or duplicate rows were present.

## ⚙️ How It Works

1. **Preprocessing:** Drop the ID column, split features/target, 80/20 train-test split, then scale features with `StandardScaler`.
2. **Modelling:** Train a **Linear Regression** model and a **Polynomial Regression (degree 2)** model on the scaled features.
3. **Evaluation:** Compare both models using MAE, MSE, RMSE, and R².
4. **Interpretation:** Standardized coefficients from the Linear Regression model show each feature's relative influence on the final marks.
5. **Deployment:** The trained Linear Regression model + scaler are saved with `joblib` and loaded inside `app.py`, a Streamlit app where a user can move sliders for attendance, test scores, assignment score, and study hours to get an instant predicted final mark, along with a chart of what drove that specific prediction.

## 📊 Model Performance (Test Set)

| Model | MAE | RMSE | R² |
|---|---|---|---|
| Linear Regression | ≈ 3.67 | ≈ 4.62 | ≈ 0.830 |
| Polynomial Regression (deg 2) | ≈ 3.66 | ≈ 4.61 | ≈ 0.830 |

Both models perform almost identically, which shows the relationship between these features and final marks is close to linear. The **Linear Regression** model is used in the deployed app for simplicity and interpretability.

## 🚀 Running the Project

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Run/re-run the notebook (optional — model files are already included)

Open `Student_Final_Marks_Prediction.ipynb` in Jupyter and run all cells. This regenerates `final_marks_model.pkl`, `feature_scaler.pkl`, and `feature_columns.pkl`, plus all EDA charts, from `Final_Marks_Data.csv`.

### 3. Launch the Streamlit app

```bash
streamlit run app.py
```

Make sure `final_marks_model.pkl`, `feature_scaler.pkl`, and `feature_columns.pkl` are in the same folder as `app.py` (they are already included in this project).

The app opens at `http://localhost:8501` in your browser.

## 🔍 Key Insights

- **Attendance**, **Internal Test 1**, **Internal Test 2**, and **Assignment Score** are the strongest positive predictors of final exam marks.
- **Daily Study Hours** has a smaller, though still positive, effect once the other academic-performance features are accounted for.
- The model explains roughly **83% of the variance** in final exam marks (R² ≈ 0.83) on unseen test data.
